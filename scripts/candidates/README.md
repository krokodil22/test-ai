# Предварительная проверка замены модели

Кандидаты запускаются отдельно от сайта. Активный `scripts/model-source.json`
меняется только после чтения настоящих результатов. Веса и Python-пакеты лежат
в игнорируемом `.cache/`; генерация не использует нейросетевые API.

Используются вопросы из `src/diagnostic-cases.json`, что применялись для
Qwen3 1.7B, и задания из `russian-screening.json`: грамматика, отрицание в
переводе и две истории. У отсеянных кандидатов набор может быть неполным;
`native-greedy-facts.json` содержит только две русские фактические задачи,
`russian-acceptance.json` объединяет их с четырьмя языковыми заданиями.
Сохраняются исходный запрос, текст, параметры, версия движка и причина окончания.
Незавершённые ответы не считаются полными. Это малый набор для отбора, не бенчмарк.

Критерии ручной оценки заданы до замены модели:

- Омлет: разбить и взбить яйца, приготовить на сковороде; без нарезания сырых
  яиц и посторонних бессмысленных действий.
- Сезоны: наклон земной оси и движение по орбите; не объяснение сменой дня/ночи.
- Грамматика: «Они идут домой».
- Перевод: свинка/свинья и сохранённое отрицание «не умеет/не может плавать».
- Бегемот: тот же герой, кусание имеет последствия, связная развязка и мораль.
- Свинка: тот же герой, исходное неумение плавать сохранено, связная развязка.
- Во всех заданиях: понятный русский, отсутствие многократных повторов абзацев.

Модели проверяются на CPU через PyTorch/Transformers в FP32 или BF16.
Gemma 3 также отдельно проверена через публичную ONNX-конверсию INT8 и
Transformers.js на CPU; затем исходные BF16-веса проверены через PyTorch.
Формат и точность обязательно сохраняются в отчёте.
Точные совпадения текстов между FP32/INT8 и браузерным Q4 не ожидаются.
