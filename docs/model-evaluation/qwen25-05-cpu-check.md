# Проверка плохого русского Qwen2.5 0.5B

28 октября 2026 года получен браузерный отчёт с шестью нейтральными вопросами.
Все 12 ресурсов прошли SHA-256 проверку; история очищалась перед каждым вопросом,
temperature 0, top_p 1. На русском модель ответила `3` на `2 + 2`, выдала
бессмысленный рецепт и повторяющееся неверное объяснение времён года.

## Первый контроль: те же сжатые веса на CPU

При первом локальном контроле скачать исходную `Qwen/Qwen2.5-0.5B-Instruct`
не удалось: сетевой шлюз возвращал HTTP 403 для Hugging Face даже после
разрешения сетевого доступа. На этом этапе исходные BF16/FP32-веса не использовались.

Вместо этого закреплённые браузерные MLC-веса q4f16_1 восстановлены в матрицы
для независимой реализации Qwen2 в Transformers 5.3.0 / PyTorch 2.6.0+cpu.
При восстановлении сохранены FP16-округление и порядок упаковки MLC, затем
вычисления шли на CPU в FP32. Использованы все 267 тензоров, тот же токенизатор,
шаблон Qwen2, системная инструкция, вопросы и пределы ответа.
Это не возвращает точность исходных весов: потерянные при сжатии значения
восстановить переводом в FP32 невозможно.

| Проверка | Браузер | Независимый CPU |
| --- | --- | --- |
| `2 + 2`, русский | `3` | `3`, дословное совпадение |
| `2 + 2`, английский | `4` | `4`, дословное совпадение |
| Омлет, русский | «омлетный орех», бессмысленные шаги | «Запейте омлетный овощной…», многократные повторы |
| Омлет, английский | Связнее, но яйца предлагается разбить повторно | Та же ошибка с повторным разбиванием яиц |
| Времена года, русский | Повторы про «законченный год/месяц» | Дословно тот же неверный ответ |
| Времена года, английский | Неверные причинные связи | Неверная причинная связь; текст короче |

Три из шести текстов совпали полностью. Все три русские задачи провалены и
при независимом CPU-вычислении. Различия остальных текстов допустимы при
FP32/FP16: небольшие различия вычислений меняют выбор следующего токена.
Замер времени облачного CPU не характеризует скорость пользовательского GPU.

Полные тексты и условия:

- [CPU-результаты](reports/qwen25-05-mlc-cpu-diagnostics.json).
- [Парное сравнение с браузером](light-cpu-browser-check.json); без данных об
  устройстве и пользовательской переписки, только фиксированные тестовые вопросы.

## Второй контроль: исходные веса без сжатия

Исходную модель удалось проверить в GitHub Actions — в том же репозитории,
где готовятся ресурсы сайта. Выполнялись только фиксированные тестовые вопросы;
пользовательская переписка не использовалась. Веса скачаны с проверкой размеров
и SHA из закреплённой ревизии `7ae557604adf67be50417f59c2c2f167def9a775`.
Файл исходных весов: 988 097 824 байта, SHA-256
`fdf756fa7fcbe7404d5c60e26bff1a0c8b8aa1f72ced49e7dd0210fe288fb7fe`.
Файл BF16 загружен без квантизации; все параметры вычислительной модели
проверены как FP32. Это не восстановленные четырёхбитные веса.

У всех шести нейтральных вопросов совпадают **все входные ID токенов** с
контролем Q4: не только видимый текст, но и системная инструкция, специальные
токены и шаблон. Совпадают параметры генерации и пределы ответа.

| Проверка | Исходная модель, FP32 |
| --- | --- |
| `2 + 2`, RU и EN | Оба ответа `4` |
| Омлет, RU | Яйца на противне, сахар, мука, «пчеловодное масло», повторяющиеся шаги |
| Омлет, EN | Связный короткий рецепт с взбиванием яиц и приготовлением на сковороде |
| Времена года, RU | «Движение солнца вокруг Земли», затем «движение Земли вдоль оси Солнца» |
| Времена года, EN | Связное объяснение с наклоном оси |
| Исправление грамматики, RU | «Они идут домой.» |
| Перевод `The pig cannot swim`, RU | «Пig niega плавать.» |
| Рассказ про бегемота | Повторяющийся диалог, исходное условие про кусание потеряно, предел 512 токенов |
| Рассказ про свинку | Жизнь и бег по океану, противоречия, многократные повторы, предел 512 токенов |

Полные [нейтральные ответы](reports/qwen25-05-original-diagnostics.json) и
[расширенная русская проверка](reports/qwen25-05-original-russian-screening.json)
содержат версии, настройки, ID токенов, SHA-256 исходных файлов и ссылку на
фактически исполнившийся workflow. Профиль модели:
`scripts/candidates/qwen2.5-0.5b.json`.

## Третий контроль: настройки действующего чата

Проверена также исходная модель с точной короткой русской инструкцией лёгкого
чата, temperature 0.7, top_p 0.8, repetition_penalty 1 и пределом 256 токенов.
Профиль `scripts/candidates/qwen25-light-production.json` сверяется с текущей
инструкцией `src/config.ts`. Это отдельные условия, их нельзя смешивать с
нейтральным жадным прогоном в единую оценку. В каждом задании свежий контекст,
seed 42; один seed не измеряет стабильность всех случайных генераций.

| Задание | Фактический результат исходной модели с настройками чата |
| --- | --- |
| Арифметика | `4` |
| Омлет | Три яйца вместо двух, вода, орехи/морковь, кастрюля под одеялом; приготовление омлета не описано |
| Времена года | «Вращение солнца вокруг Земли», бессмысленные рассуждения про ветер |
| Грамматика | «Домой идут они» — грамматически исправлено, но изменён порядок слов |
| Перевод | «Пig ne может плавать.» — смесь алфавитов и языков |
| Бегемот | Объявлен растительным организмом; рассказ заменён списком нелепых утверждений, предел 256 токенов |
| Свинка | Бессвязные события с войной и бродягами; поучительный сюжет не получился |

Полный [отчёт с настройками чата](reports/qwen25-05-original-production.json)
содержит все семь ответов. Смена инструкции и sampling не устранила ключевые
ошибки. Причина плохого русского не сводится к диагностической temperature 0.

## Вывод

Грубые ошибки текущего Q4-комплекта воспроизводятся вне WebLLM/WebGPU.
Замена только библиотеки выполнения не имеет подтверждённого основания.
Это не доказывает отсутствие всех ошибок GPU.

Исходный контроль показал две проблемы: Q4-комплект дал худшую арифметику и
английские ответы, но грубые смысловые ошибки русского есть и без сжатия.
Потери квантизации и возможные дефекты upstream-конверсии отдельно не разделены. Исправление
только формата весов не имеет подтверждённой перспективы достаточного русского
качества. Восемь бит или сохранение точности embeddings/output не объявляются
проверенным исправлением; исходная модель уже проваливает ключевые задания.
Рабочая русская инструкция и sampling также не дали приемлемого результата.
Для русского помощника по разным темам у Qwen2.5 0.5B нет подтверждённого
качества. Увеличивать её загрузку ради 8 бит на основании этих тестов не стоит;
следующим экспериментом должен быть другой кандидат с предварительным отбором.

Ни модель по умолчанию, ни параметры генерации сайта этой проверкой не изменены.

## Воспроизведение

После подготовки лёгкой модели (`npm run model:download:light`) и установки
CPU-зависимостей из `scripts/reference-requirements.txt` в отдельное окружение:

```sh
python scripts/run-mlc-cpu-reference.py --verify-only
python -m unittest discover -s tests/python -v
python scripts/run-mlc-cpu-reference.py --threads 4 \
  --output .cache/reference/qwen25-05-mlc-cpu-diagnostics.json
```

Для исходного контроля при доступном Hugging Face:

```sh
npm run reference:download -- --profile scripts/candidates/qwen2.5-0.5b.json \
  --output .cache/reference/qwen25-05-original
python scripts/run-reference.py --profile scripts/candidates/qwen2.5-0.5b.json \
  --model .cache/reference/qwen25-05-original --dtype float32 --threads 4 \
  --output .cache/reference/qwen25-05-original-diagnostics.json
python scripts/run-reference.py --profile scripts/candidates/qwen2.5-0.5b.json \
  --model .cache/reference/qwen25-05-original --dtype float32 --threads 4 \
  --cases scripts/candidates/qwen25-light-production.json \
  --output .cache/reference/qwen25-05-original-production.json
```

Повторить контроль на GitHub можно через workflow **Check original Qwen2.5 0.5B**
(`.github/workflows/light-model-reference.yml`, кнопка Run workflow).
Он сохраняет только отчёты и хеши, не веса. Статус workflow проверяет полноту
эксперимента; успешное выполнение не означает, что ответы качественные.

Все Python-вычисления нужны разработчику. На сайте по-прежнему только
статические файлы и локальная браузерная генерация.
