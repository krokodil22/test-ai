# Повторный отбор компактной модели для русского чата

Проверка выполнена 28 октября 2026 года. Цель — найти вариант легче Qwen3.5 4B,
который заметно улучшит русский относительно текущей Qwen2.5 0.5B и сможет
рассматриваться для ноутбуков с 4 ГБ. Аппаратная работа на 4 ГБ в этом отборе
не проверялась. Итог: **подходящей замены среди проверенных вариантов нет**.

## Метод

[Каталог](compact-catalog.json) содержит 89 публичных записей: закреплённые
ревизии, лицензии, размеры исходных весов, семейство архитектуры и шаблон чата.
Это первичный поиск, не список 89 испытанных моделей. Англоязычные базовые,
речевые модели, неподдерживаемые архитектуры, адаптеры без полных весов и
ранее отклонённые варианты отсеивались до загрузки крупных файлов.
Для LFM2/LFM2.5 и Gemma 4 готового пути через используемый MLC нет; их качество
здесь не измерялось.

Исходные веса выбранных кандидатов скачаны с SHA/размерами из неизменяемых
ревизий и загружены на CPU в FP32. Использованы PyTorch 2.6.0+cpu и
Transformers 5.3.0, дополнительно 4.51.3 и 5.8.1 для контрольных запусков.
Сжатые браузерные комплекты кандидатов не выдаются за проверенные.

Первый профиль — шесть нейтральных RU/EN вопросов из
`src/diagnostic-cases.json`. Второй — семь русских заданий с точной короткой
инструкцией лёгкого чата, sampling 0.7 / 0.8, repetition_penalty 1 и пределом
256 токенов (`scripts/candidates/qwen25-light-production.json`).
Результаты этих условий оцениваются раздельно. Грамматика, перевод, рецепты,
сезоны, сохранение героя, завершённость и повторы проверялись по критериям
`scripts/candidates/README.md`; фактические ошибки не объявляются успехом.

В каталоге число параметров берётся из метаданных safetensors: оно может
включать повторно записанные связанные матрицы. Размер исходного BF16/FP16
файла не равен загрузке WebLLM и не определяет расход RAM посетителя.

## Результаты

| Кандидат | Что фактически обнаружено |
| --- | --- |
| Qwen3 0.6B, без рассуждений | `2 + 2 → 2` на обоих языках; бессмысленные русские шаги омлета; ошибка в грамматике; противоречивый рассказ |
| Vikhr Qwen2.5 0.5B Instruct | В рабочем режиме `2 + 2 → 2`; `pig` превращается в «питеня»; бегемот с шерстью, потеря условий рассказа |
| QVikhr 3 1.7B Instruction noreasoning | Арифметика, грамматика и короткий перевод лучше; неверные рецепт и сезоны, бессвязная история про свинку |
| Vikhr Llama 3.2 1B Instruct | «Солнце вращается вокруг Земли», выдуманные слова в рецепте, бегемот с четырьмя хвостами; предел рассказов достигнут |
| Vikhr Qwen2.5 1.5B Instruct | «Курица» вместо свинки, неверная причина сезонов, смешение языков и бессвязные фразы; рассказы не закончились |
| QVikhr 2.5 1.5B Instruct-r | «Кондор» вместо свинки, китайский фрагмент в объяснении сезонов; свинка тонет, а мораль утверждает спасение |
| ZaryaOrthrus 0.6B, обычная AR-часть | Полный обычный режим и облегчённая часть численно совпали; все 13 текстов совпали с неудачным запуском Qwen3 0.6B |

У Vikhr Llama 1B прежний нейтральный тест уже находил ошибку сезонов; в этом
раунде впервые проверены семь заданий с короткой русской инструкцией и sampling.
Остальные приведённые новые checkpoint не подменяют ранее испытанный SMPO
вариант QVikhr: у каждого своя закреплённая ревизия.

Qwen3 0.6B отдельно проверена с включёнными рассуждениями: арифметика стала
правильной, но в рецепте появились «лавандовый орех» и оставление блюда на
несколько часов, а причины сезонов так и не были объяснены. Рассуждения
увеличили число генерируемых токенов; улучшение ключевых заданий не подтверждено.

Полные тексты, ID входных токенов, причины окончания и SHA исходных файлов
сохранены в [compact-results/](compact-results/). Окончание `length` означает
незавершённый ответ, а не успешно выполненное задание.

## Контроль версий и загрузки весов

Неожиданные провалы маленьких моделей перепроверены до выводов:

- Для Qwen3 0.6B все 13 ответов совпали между Transformers 4.51.3, 5.3.0 и 5.8.1.
- Для Vikhr Qwen2.5 0.5B все 13 ответов также совпали между этими тремя версиями.
- Исходная обычная Qwen2.5 0.5B дополнительно проверена в 4.51.3;
  прежние выводы о плохом русском сохранились.
- Для контрольных запусков побайтово проверены исходные матрицы embeddings /
  lm_head и значения после загрузки с обратным приведением к исходной точности.
  Самовольная замена этих весов не обнаружена.
- Неполная загрузка, неизвестные параметры и несовпадающие формы запрещены.
  Такие случаи записываются как ошибки выполнения, не как плохое качество модели.

Это контроль проверенных программных условий, не доказательство одинакового
поведения при любой точности, любом устройстве или любом запросе.

## Особый контроль ZaryaOrthrus

Первичная попытка стандартной загрузки выявила 168 дополнительных параметров
`*_diff` и была отклонена. Считать такой частично загруженный checkpoint
полноценной Zarya было бы неверно.

Затем изучен [исходный код](zarya-source-review.json), закреплённый SHA-256
`7e8f4e01c4c8c469866839976acd6fa45dec207af40d939e0a46b8918e413334`.
В `OrthrusAttention.forward` при `is_diffusion_pass=False` вызывается
стандартный Qwen3Attention; `generate(use_diffusion_mode=False)` использует
обычный GenerationMixin. Поэтому отдельно проверена именно **обычная
авторегрессионная часть**, без диффузионного ускорения.

Отбрасывание параметров разрешено только для точного набора из 168 известных
вспомогательных тензоров; все параметры обычной части обязательны. Затем
полный исходный класс и обычный Qwen3 вычислены в FP32 с теми же весами:
сравнены логиты **всего словаря** на двух запросах после prefill и после одного
шага с KV-кешем. Максимальная абсолютная разница — **0** во всех случаях.
После этого выполнены те же шесть контрольных и семь рабочих заданий.

Все 13 ответов совпали с Qwen3 0.6B. Код обучения из официального
`ai-forever/Zarya-Orthrus@a2e5f830ff9e2a4f5b199bf7566bc0d5f58fa642`
обучает дополнительные `*_diff` ветки с замороженным основным блоком;
русскоязычные данные служат ускорению, а не подтверждённому улучшению
языковой модели. Полная диффузионная генерация в браузере не проверялась и
не заявляется поддержанной. [MIT-уведомление исходного кода](Zarya-Orthrus-MIT.txt).

## Решение

Ни один из этих вариантов не выбран для замены на сайте: грубые ошибки есть
до браузерного сжатия. Рабочая Qwen3.5 4B в экономичном режиме остаётся
основной. Это не означает, что другие компактные модели в принципе невозможны;
данный отбор не дал подтверждённого улучшения для русского помощника по разным темам.

Новые наборы WebLLM и их минимальные требования для 4 ГБ не объявляются
готовыми: замер размера загрузки и проверка GPU имеют смысл после достаточного
качества исходного кандидата. В этом раунде нет результатов на реальном
устройстве с 4 ГБ и нет измерений его RAM/VRAM.

## Воспроизведение

Профили с точными model/revision/files находятся в `scripts/candidates/compact-*.json`.
Списки раундов: `compact-round1-selection.json`, `compact-round2-selection.json`,
`compact-round3-selection.json`; текущий `compact-selection.json` содержит AR-контроль Zarya.
Workflow **Screen compact model Russian quality** читает этот список и сохраняет
все результаты, включая ошибки выполнения. Для повторения предыдущего раунда
нужно выбрать соответствующий сохранённый список как `compact-selection.json`.
Успешный статус workflow означает завершённый эксперимент, не успешное качество.

На машине разработчика с установленными зависимостями из
`scripts/reference-requirements.txt` можно запустить один пункт текущего списка:

```sh
node scripts/candidates/run-compact-screen.mjs zarya-orthrus-native-ar
python -m unittest discover -s tests/python -v
```

Версии Transformers в повторных запусках задаются соответствующим списком;
локально их необходимо установить отдельно. Все тестовые генерации используют
фиксированные публичные запросы. Пользовательская переписка не передавалась
в GitHub Actions или API нейросетей; на сайт Python и исходные веса не попадают.
