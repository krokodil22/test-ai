# Поиск замены модели

Для пробной замены выбрана **Qwen3.5 4B / q4f16_1**, загрузка 2 087 067 782
байт. Пользователь разрешил увеличить предел до 2,1 ГБ после измерения комплекта.
Это улучшение коротких фактических ответов, а не устранение всех проблем русского.
В рассказах остаются существенные ошибки: в жадном прогоне свинка «ходит по
воде», в прогоне с сокращением объёма у бегемота появляется рог, а у истории
про свинку противоречивая развязка. Эти задания **не объявляются пройденными**.
Окончательные тексты доступны без пересказа в JSON ниже.

Результаты получены локальной генерацией на CPU, без API нейросетей. Веса
скачиваются с проверкой размеров и контрольных сумм из закреплённых ревизий.
Это небольшой отбор на конкретных задачах, **не оценка качества на всех темах**.
Ответы, исходные запросы, настройки, точность и версии движка сохранены в
[`reports/`](./reports/). Неполные запуски имеют `complete: false`.

Проверяются инструкция про омлет, объяснение времён года, исправление грамматики,
сохранение свинки и отрицания при переводе, истории про свинку и бегемота.
У отсеянных кандидатов оставшиеся задания могут не выполняться. Использовались
нейтральный и рабочий системные запросы, жадное декодирование и рабочие настройки;
эти условия указаны в каждом JSON, их нельзя смешивать в общий числовой рейтинг.
Критерии до отбора: [`scripts/candidates/README.md`](../../scripts/candidates/README.md).

[`qwen35-4b-neutral-reference.json`](reports/qwen35-4b-neutral-reference.json)
содержит те же шесть нейтральных RU/EN вопросов, что контроль прежней Qwen3 1.7B.
[`qwen35-4b-russian-screening.json`](reports/qwen35-4b-russian-screening.json)
содержит расширенный жадный прогон с рабочей русской инструкцией.
[`qwen35-4b-compact-sampling.json`](reports/qwen35-4b-compact-sampling.json)
использует текущую инструкцию с ограничением объёма и sampling 0.7 / 0.8 без
штрафов. Изменение инструкции и sampling явно записано; оно не выдаётся за
сравнение при неизменных настройках. Все шесть ответов этого прогона завершились
до лимита, но завершённость не равна правильности смысла.

Настоящий холодный импорт нового архива в Chromium проверен отдельно:
[`qwen35-archive-import-check.json`](qwen35-archive-import-check.json).
Проверены все 82 файла и повторное использование кеша, без GPU-генерации.

Измерены также два **подготовленных, но не выбранных** комплекта WebLLM:
Qwen3 4B Instruct 2507 — 1 990,4 МБ, Phi‑4 mini — 1 908,1 МБ,
включая gzip-веса, WASM, конфигурацию и токенизатор. Это десятичные МБ,
не размеры исходных BF16/FP32-весов. Эти файлы не добавлены в Git.

CPU-проверка исходных весов не подтверждает качество четырёхбитной версии на GPU.
В этой облачной среде нет совместимого адаптера `shader-f16`, поэтому аппаратная
генерация WebLLM не заявляется проверенной. Проверки интерфейса с тестовым движком
проверяют логику приложения, а не качество модели.

## Повторить проверку

```sh
npm ci --ignore-scripts
npm run reference:download -- --profile scripts/candidates/phi4-mini.json --output .cache/reference/phi4-mini
python3 -m venv .cache/reference-venv
.cache/reference-venv/bin/pip install -r scripts/reference-requirements.txt
OMP_WAIT_POLICY=PASSIVE .cache/reference-venv/bin/python scripts/run-reference.py --profile scripts/candidates/phi4-mini.json --model .cache/reference/phi4-mini --cases scripts/candidates/russian-screening.json --dtype bfloat16 --threads 2 --output .cache/reference/recheck.json
```

Исходные веса нужны только разработчику для отбора. Python и PyTorch не попадают
на сайт и не требуются посетителям. BF16 используется только на поддерживающем
его CPU; для других процессоров доступен `--dtype float32` с большим расходом RAM.
Для текущей Qwen3.5 закреплена Transformers 5.3.0; версия, реально создавшая
каждый прежний отчёт, указана внутри JSON. Старые результаты не пересоздавались
и не выдаются за результаты новой модели.
